# Plantify — prototype mobile
Ouvrir `index.html` dans un navigateur.
Le prototype contient 6 écrans et une navigation fonctionnelle.
Le scanner permet de choisir/prendre une photo sur téléphone et l'affiche dans le prototype.
La reconnaissance affichée est actuellement une démonstration (Monstera 98%). Pour une vraie reconnaissance IA, il faudra connecter une API de reconnaissance de plantes et une base de données.
